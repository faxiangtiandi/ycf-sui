# 🎬 导演级分镜生成器（小说漫改专属）
一款基于大模型的小说漫改分镜自动生成工具，支持智能推荐适配导演、生成导演风格指令、结构化分镜创作、分镜一致性校验等核心功能。

## 📋 项目介绍
### 核心功能
- 🧠 智能推荐：根据小说题材自动推荐适配的导演列表
- 🎨 风格生成：生成选中导演的视觉风格指令（色调/光影/构图/节奏）
- 🎬 分镜创作：生成结构化的动态漫分镜（含中文/英文提示词、视频提示词）
- 🔍 质量校验：校验分镜人物/空间/风格一致性，一键应用优化建议
- 📝 便捷复制：所有提示词自带复制按钮，支持批量导出

### 技术栈
- 核心框架：Streamlit（快速构建Web UI）
- 大模型调用：支持DeepSeek/火山方舟/OpenAI/智谱AI/百度文心/阿里云通义千问
- 工具库：requests（API调用）、tenacity（重试机制）、uuid（唯一标识）

## 🛠️ 环境要求
- Python 3.8+
- 依赖库：见`requirements.txt`
